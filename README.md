欢迎来到我的本科代码考古现场。这个仓库用于归档本科期间写过的 C/C++ 代码，而且全部是在毫无 AI 参与的情况下手工完成——代码是纯手写的，bug 当然也是纯天然的。它更多是学习记录，而不是持续维护的软件项目；部分程序依赖当时的开发环境、目录结构和测试数据，重新运行时可能需要适当调整。

## 文件介绍

- `dip_hw3/`：数字图像处理（Digital Image Processing）课程的第三次作业，使用 C++ 和 OpenCV 实现边缘检测与霍夫圆检测。
- `factorial`：大数阶乘的实现。由于 `int`、`long long` 等基本整数类型无法存储较大的阶乘结果，本程序使用一个整型数组按十进制位保存大整数，并通过逐位乘法计算阶乘。
