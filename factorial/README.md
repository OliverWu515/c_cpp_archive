# Factorial

大一 C 语言课程作业，大整数阶乘计算程序。由于 `int`、`long long` 等基本整数类型无法存储较大的阶乘结果，本程序使用一个整型数组按十进制位保存大整数，并通过逐位乘法计算阶乘。

## 功能

程序依次计算并输出：

```
1!
2!
3!
...
40!
```

每计算一次阶乘，就输出当前结果。

## 实现思路

程序使用长度为 `50` 的整型数组：

```
#define CON 50
int dashu[CON];
```

数组中的每个元素保存十进制数的一位，并采用**低位在前、高位在后**的方式存储。

例如：

```
12345
```

在数组中表示为：

```
dashu[0] = 5
dashu[1] = 4
dashu[2] = 3
dashu[3] = 2
dashu[4] = 1
```

初始时：

```
dashu[0] = 1;
```

表示当前结果为 `1`。

随后依次乘以：

```
1, 2, 3, ..., 40
```

从而得到对应的阶乘结果。

## 主要函数

### `calculate`

```
void calculate(int dashu[], int n21)
```

将当前保存的大整数乘以 `n21`。

程序从最低位开始逐位计算：

```
dashu[i] = dashu[i] * n21 + a21;
```

其中 `a21` 保存进位。

随后：

```
a21 = dashu[i] / 10;
dashu[i] = dashu[i] % 10;
```

分别得到新的进位和当前位数字。

### `print`

```
void print(int dashu[])
```

用于输出数组中保存的大整数。

由于数组采用低位在前的方式保存数字，因此输出时需要从最高的非零位开始逆序输出。

## 编译

使用 GCC：

```
gcc factorial.c -o factorial
```

## 运行

Linux / macOS：

```
./factorial
```

Windows：

```
factorial.exe
```

## 示例输出

程序开始时的部分输出如下：

```
1
2
6
24
120
720
5040
40320
362880
3628800
...
```

最后一行为：

```
815915283247897734345611269596115894272000000000
```

即：

```
40!
```

## 说明

该程序主要用于演示：

- C 语言数组的使用
- 大整数的简单表示方法
- 手工模拟十进制乘法
- 进位处理
- 阶乘的迭代计算

这种方式不依赖额外的大整数库，适合作为大整数运算的基础练习。
