# Big Integer Addition

大一 C 语言课程作业，大整数加法。程序将两个非负整数以字符串形式读入，通过逐位相加和进位处理完成计算，因此可以处理超过普通整数类型范围的数字。

## 实现思路

程序使用字符数组保存输入：

```
char A[N], B[N], C[N];
```

计算时先比较两个数字的长度，并保证较长的数字作为 `addition()` 的第一个参数。

加法从低位向高位进行：

```
C[i] = (c + temp) % 10;
temp = (c + temp) / 10;
```

其中 `temp` 用于保存进位。

当两个数字长度不同，会将较短的数字按个位与较长数字对齐。

例如：

```
12345
  678
-----
13023
```

最高位单独处理。程序允许 `C[0]` 保存大于 `9` 的值，因此也能正确处理最终产生新一位的情况，例如：

```
999 + 1 = 1000
99 + 99 = 198
```

## 编译

```
gcc big_add.c -o big_add
```

## 运行

```
./big_add
```

示例输入：

```
12345 678
```

输出：

```
13023
```

## 说明

该程序主要演示：

- 使用字符串保存大整数
- ASCII 字符与数字之间的转换
- 不同长度数字的对齐
- 十进制逐位加法
- 进位处理

## 限制

- 仅支持非负十进制整数
- 最大输入长度由 `N` 决定，目前为 `50`
- 未完整检查输入是否合法
- `scanf("%s%s", ...)` 未限制输入长度，过长输入可能导致数组越界
